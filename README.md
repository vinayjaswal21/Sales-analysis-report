# Sales-analysis-report
I developed a comprehensive project in Excel, creating multiple dashboards and tables to analyze the data. This process involved several stages, including data processing, data cleaning, and data visualization.

# Objective 
I created an annual sales report for Vrinda store, so that they can understand their customers and grow more sales.

# Dataset used :
- <a href="https://github.com/vinayjaswal21/Sales-analysis-report/blob/main/Vrinda%20Store%20Data%20Analysis.xlsx">Dataset</a>

# KPIs

- Compare the sales and orders using single chart
- Which month got the highest sales and orders?
- Who purchased more - men or women in 2022?
- What are different order status in 2022?
- List top 10 states contributing to the sales?
- Relation between age and gender based on number of orders
- Which channel is contributing to maximum sales?
- Highest selling category?
